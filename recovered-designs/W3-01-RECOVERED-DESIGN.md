**Status:** PARKED / DO NOT EXECUTE

**Funds:** Zero real funds; testnet only  
**Purpose:** Prove JARVIS/PRIME can govern a blockchain transaction lifecycle while PRIME retains exclusive economic authority.

## Recovered invariants

1. Web3 capability ≠ Web3 authority.
2. PRIME retains exclusive economic/signing authority.
3. Specialist agents never receive the private key.
4. A disposable testnet key resides only within the PRIME/ABEX authority boundary.
5. Risk tier derives from the actual proposed action, not an agent's self-classification.
6. Wallet signing, contract deployment and asset transfer default to the highest applicable risk tier.
7. An agent may make its own handling stricter, never less restrictive.
8. Proposal-time approval is not execution-time authorization.
9. Execution-time revalidation is mandatory because blockchain state may change between proposal and execution.
10. No real funds, production wallets, speculative trading, meme coins, NFTs or unrelated Web3 expansion belong to W3-01.

## Recovered intended lifecycle

Specialist agent proposes action  
→ PRIME derives risk  
→ authority boundary evaluates proposal  
→ execution conditions revalidated  
→ PRIME-controlled testnet key signs  
→ transaction submitted  
→ result/state verified  
→ provenance/evidence receipt retained.
